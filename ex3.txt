PART D
# 1. Create permissions directory, files, and set octal permissions
mkdir permissions
cd permissions
touch secret.txt shared.txt public.txt

# secret.txt -> owner read/write (6), no one else (00)
chmod 600 secret.txt

# shared.txt -> owner and group read/write (66), others read (4)
chmod 664 shared.txt

# public.txt -> everyone read, write, execute (777)
chmod 777 public.txt

# 2. Check umask, create a new file, and explain permissions
umask
touch test_file.txt
ls -l test_file.txt

EXPLANATION:
When a new file is created, the system assigns a default base permission of 666 (rw-rw-rw-). However, the actual permission is determined by subtracting the umask value from this base permission (Base - Umask). 
For example, if my umask is 0022, the final permission for test_file.txt is 666 - 022 = 644 (rw-r--r--). This means the owner can read/write, while the group and others can only read.
